JEVORA Technologies — Logo integrated portfolio
================================================

- The uploaded JEVORA Technologies logo is embedded into the navbar and footer.
- The logo is also embedded as a favicon.
- A light background tile is used in the dark navigation so the original dark lettering remains readable.
- The single HTML file includes all styling and preview images and needs no separate assets folder.
- Pure HTML + CSS; no JavaScript or framework.
- GitHub Pages: upload index.html to your repository root and enable Pages from Settings -> Pages.
- Existing solution categories, demo links, work cards and contact details were retained.
